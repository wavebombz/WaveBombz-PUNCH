# WaveBombz PUNCH

A JUCE 8 / C++17 VST3 transient shaper and punch enhancer for electronic music production.

## Project status

Initial repository bootstrap. DSP and interface implementation are being developed in staged, buildable increments.

## Planned features

- Transient shaping: Attack and Sustain
- Punch enhancement
- Input / Output gain and Dry/Wet mix
- Optional soft clipping
- Selectable 2x / 4x / 8x oversampling
- Peak and RMS metering
- Factory presets and user preset support
- Resizable dark graphite / amber interface

## Build

The project uses CMake and JUCE 8, with a Windows x64 VST3 build planned through GitHub Actions.

See `docs/DEVELOPMENT.md` for the implementation roadmap.
